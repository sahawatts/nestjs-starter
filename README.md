# NestJS Course REST API

This project is a complete NestJS REST API application generated as part of a course. The entire codebase was built by the Gemini CLI, following a syllabus that was originally generated by NotebookLM from a YouTube video.

## Origin

The foundation of this project is a course syllabus for a NestJS REST API. This syllabus was created by NotebookLM, which processed a YouTube video to extract the course structure and content. You can watch the original video [here](https://youtu.be/8_X0nSrzrCw?si=u_gpqPW5L4c1aUr0).

The Gemini CLI then used this syllabus as a blueprint to generate the entire NestJS application, including:

*   Modules and controllers
*   Services and dependency injection
*   Data transfer objects (DTOs) and validation
*   Database integration with TypeORM
*   Error handling, logging, and other advanced features

This project serves as a practical example of how AI tools like NotebookLM and the Gemini CLI can be used to accelerate the learning and development process, from concept to a fully functional application.

## Running the Application

```bash
# Install dependencies
npm install

# Run the development server
npm run start:dev
```

The API will be available at `http://localhost:3000`.

## Dependencies by Chapter

### Chapter 1: Getting Started with NestJS

**Installation**
```bash
# Install NestJS CLI globally
npm install -g @nestjs/cli
```

**Common CLI Commands**

The NestJS CLI is a powerful tool for scaffolding your application. Here are some of the most common commands and their shorthands:

| Full Command                  | Shorthand         | Description                                                                 |
| ----------------------------- | ----------------- | --------------------------------------------------------------------------- |
| `nest new <project-name>`     | `nest n`          | Creates a new NestJS project.                                               |
| `nest generate module <name>`   | `nest g mo <name>`  | Generates a new module.                                                     |
| `nest generate controller <name>` | `nest g co <name>`  | Generates a new controller.                                                 |
| `nest generate service <name>`  | `nest g s <name>`   | Generates a new service.                                                    |
| `nest generate resource <name>` | `nest g res <name>` | Scaffolds a complete CRUD resource (module, controller, service, DTOs).     |
| `nest generate library <name>`  | `nest g lib <name>` | Generates a new library in a monorepo.                                      |
| `nest start`                  | -                 | Compiles and runs the application.                                          |
| `nest start --watch`          | `nest start:dev`  | Runs the application in watch mode for development.                         |
